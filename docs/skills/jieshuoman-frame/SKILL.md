# 解说漫画面规则（frame）

从小说到解说漫只有两根杆：**旁白**（jieshuoman-hit-rules R0）和**画面**（本 skill）。本 skill 回答一个问题：**原著里哪些物品、描述、处境要翻译成一帧画面，翻译成什么等级的画面。**

来源与 jieshuoman-hit-rules 相同：15 部竞对爆款拉片 + 3 组同底本对撞（九州胜/RS 败，含投放端素材对比表）+ 12 部爆款开场逐句拉片。规则编号沿用母 skill（R0b、R1、R12–R17、R14b、R22），两边冲突时以母 skill 为准。

## 1. 三级画面（每一帧都要标级）

| 等级 | 定义 | 验收 | 对应规则 |
|---|---|---|---|
| 一级·关键帧 | 可独立截图投流，陌生人 1 秒读懂冲突/反差/处境 | 能进起量素材五件套 | R14、R14b |
| 二级·身份帧 | 不一定能投流，但一帧强化男主/女主的身份、处境、人设 | 删掉这一帧，观众对角色的认知缺一块 | R1 五要素、R12、R15、R17 |
| 三级·过场帧 | 既不投流也不加身份信息 | 一句旁白带过（R3），或直接删 | R3、R11 |

**硬约束**
- 每场戏至少一帧二级以上；
- 三级帧占比 ≤ 20%；
- 一级帧密度：每 60–90 秒一帧（R14），剧本层预埋，不靠后期碰运气。

原著描述能升一级就升一级；升不到一级至少做成二级；做不成二级的不进画面——旁白一句带过或删。

## 2. 翻译动作：五问定级

拿到原著一段描述，依次问：

1. 这段里的处境/人设/信息**能挂在哪个实物上**？
2. 这个实物**能不能让女主亲眼看见**？
3. 看见之后她**有没有风险或信息差**？
4. 它能不能**持续留在画面里**（不止一个镜头）？
5. 它**强到不用旁白解释**吗？

五问全过 = 一级；过三问 = 二级；一问都过不了 = 三级。

## 3. 画面感五要素（同底本对撞实证：logline 一样时，画面感强的赢）

1. **信息实物化**：信息挂在可拍的实物上，不靠电话/听觉/旁白转述。
   - ✕ 接到电话说有个 CEO nanny 的工作（零画面）
   - ✓ 雨里绝望抬头，电线杆上贴着 “CEO Nanny Wanted” 海报——实物 + 可截图投流 + 女主下一秒就能行动（R18）
2. **女主目击**：人设/设定不靠展示，靠女主亲眼看见。
   - ✕ CEO 深夜在花园开枪，无目击者、无因果
   - ✓ 女主从虚掩的门缝看见男主在办公室杀人，一帧立住人设
3. **目击附带风险或信息差**：门是虚掩的 = 随时被发现；她知道了，他不知道她知道。目击本身就是下一个钩子。
4. **处境用物不用情绪**：持续状态挂在持续存在的实物上，不靠一次性动作和表情。
   - ✕ 女奴被鞭打、在哭（动作 + 表情，静帧读不出处境）
   - ✓ 白天把她关进笼子：实物、一帧读懂、一直在画面里、路人经过即当众性，白天亮色还做了反讽
   - 判断：静帧截图给陌生人，1 秒内能不能说出“她是什么处境”？
5. **实物够强时旁白闭嘴**：一身黑的女人捧着罐子，不说话，观众自己推出“骨灰”；小孩被装进木箱高高吊在院子里，一帧同时交代“被霸凌”和“所有人都知道、没人管”。观众自己推出来的结论比旁白告诉的强一倍。
   - 与 R12 互补：信物需要点名时，旁白点名即同帧；不需要点名时，旁白沉默。

**四问验收（每个关键设定）**：女主是从哪一帧看见的？那一帧能不能截图投流？看见后她多了什么风险？处境挂在哪个实物上？缺一打回。

## 4. 施害残留（开场 ≤15 秒施害的画面要求）

施害必须是可拍事件（物理伤害、羞辱性处境、当众被无视），情绪描述不算。**施害必须留残留物**：一巴掌、一句羞辱画面一过就没了；合格的施害要在女主身上/画面里留下至少持续一整场戏的可见痕迹——泼一身红酒、烙印、剪掉的头发、撕破的裙子、笼子。

残留物的价值：
- 一帧读懂处境，不用重演施害；
- 残留在画面里的每一秒都是势能账户的持续充电（R6）；
- 后续任何场景都能截出投流帧（R14b）。

**验收**：施害发生后 60 秒截一帧静帧，还能看出她刚被害过吗？不能 → 换一种会留痕的施害。12 部开场爆款里只有 3 部合格，这是同底本对撞里最便宜的超车点，我方改编必补。

## 5. 转折实物的稳定性：空间 > 物 > 人

- **空间**（三楼禁区、玻璃笼）不会离场，最稳；
- **物**（传单、分屏、印记）可能丢；
- **人**（丈夫、孩子、三兄弟）会离场——“丈夫被支开”即失效实证。
- **人作信物时，必须配一个不离场的物**（戒指/奴印/孩子的手绳）。

## 6. 可拍性置换（logline 与人设）

小说可以写形容词，解说漫里每个性格词/状态词必须有一帧对应画面。拍不出来就**置换成反差动作**，不是删掉：
- “不安分” → 小女孩举枪扫射
- “冷漠” → 婚礼上看手机
- “穷” → 名牌店门口数硬币

反差是首选，因为一帧同时给出前提和好奇（小女孩 × 枪 = 两个信息）。

## 7. 画面语法（R12–R17）

- **R12 秘密/身份挂实体信物**：WANTED 海报、机场名牌、家族令牌、水晶心、伤疤。旁白每次点名，画面同帧出现。改编第一问：“女主的秘密能不能拍成一帧？”不能 → 置换为可视化秘密（外貌/身体/身份/物证；北美女频默认优先身材反差），并做合规审计。
- **R13 UI 是第二旁白轨**：现代皮 = 聊天气泡/拉黑弹窗/短信/群聊照片瀑布；科幻皮 = 全息状态卡/价格钮/警告卡；神话皮 = 人物卡/怪物卡。UI 由后期模板贴片，不算“画面里的文字”。
  - **禁止把未奔现的线上关系拍成物理同框。**
  - **线上身份必须有 UI 实体**：“假装美女”不可拍，要落成精修头像、点赞数、emoji、聊天气泡、滤镜前后两张图。标准做法是**分屏**：左屏美女人设，右屏外真人吃薯片——一帧同时完成反差、观众领先、可投流素材。
  - 内心戏可选 Q 版 cutaway/表情包镜头。
- **R14 梗帧密度**：每 60–90 秒一帧可独立截图投流的画面（玻璃展柜拍卖、蛇尾绕王座、手机屏里是他俩/屏外是她的泪）。
- **R15 反差用视觉写**：卫衣素颜 vs VIP 名牌；需要变身就显式变身（造型戏后换形象）；反差两端都要拍到。
- **R16 尺度按投流性设计**：敏感内容只有两种处理——可投暗示（全黑画面 + 旁白“我腿都软了”，或门后喘息 + 画外台词），或者不拍。明拍擦边 = 成本花了、素材不能剪、还有政策风险。震撼/初见名场面给 3–6 秒静默停帧，计入关键帧配额。
- **R17 选角/造型 premise 优先于颜值**：XXL 就真胖、奴隶就真脏、素人不配高定。美感靠打光构图给，不靠改人设给。

## 8. 情绪峰值不封顶（R22）

卡点场情绪必须拍到极值：崩溃就崩溃到底（伏案痛哭/跪地/砸桌），不做“相对平和”的克制处理。竞品的起量卡点就是情绪极值帧；我方同节拍“反应相对平和”只能改做闪回，剪不出起量点。

注意：哭是状态，峰值帧要拍成动作/姿态的极值，并在峰值前用旁白铺垫（母 skill R0 通道①）。

## 9. 亮度与可读性

亮度是“世界观的天气”，按题材档取值（马甲快嘴 76–93、网恋校园 ~98、消失追悔 84–98、古风慢炖 63–79、spice 暗调 ~46）；亮色可做反讽（最亮的婚纱白讲最冷的忽视）。**唯一硬线：无论多暗，脸和信物必须读得清。**

## 10. 起量素材五件套（R14b，必填输出）

改编定稿必须附清单，标明每件落在哪一集哪一场：

| # | 素材类型 | 画面要求 |
|---|---|---|
| ① | 冲突帧 | 可拍物理对抗（拎起/推搡） |
| ② | 反差偶遇帧 | 身份/境遇落差同框 |
| ③ | 崩溃峰值帧 | 见 R22 |
| ④ | 物证悬置钩 | 伤疤外露 + 门突然响 |
| ⑤ | 对峰质问帧 | “Tell me, did you really betray me?” |

每件配一句素材旁白并标 R0 通道（①共情 / ②领先 / ③落差），**前 3 秒必须命中其一**；对话不能替代素材旁白。缺任一件，投放端就剪不出该类起量素材。

## 工作流

**改编（小说 → 画面方案）**
1. 判题材档，定亮度区间。
2. 逐段过原著描述：五问定级（§2），能升就升。
3. 关键设定逐个过画面感四问（§3）；抽象词做可拍性置换（§6）。
4. 开场施害补残留物（§4）；转折实物按稳定性选型，人配物（§5）。
5. 套画面语法 R12–R17、峰值 R22。
6. 输出逐帧标级表 + 五件套清单 + 验收表。

**评审/拉片（剧本或成片）**
1. 逐场列帧，标一/二/三级，统计三级占比与一级帧间隔。
2. 逐条过下方 checklist，✓/✕ + 时间点证据。
3. 不合格项给出具体改法（换什么实物、加什么残留、哪一帧升级），不做笼统评价。

## 输出格式

**逐帧标级表**

| 集-场 | 时间点 | 画面描述 | 等级 | 挂载实物 | 女主目击? | 风险/信息差 | 可投流? | 改法（如需） |
|---|---|---|---|---|---|---|---|---|

**统计**：每场二级以上帧数 / 三级帧占比 / 一级帧平均间隔。

**五件套清单**：类型 / 集-场 / 画面 / 素材旁白 / R0 通道。

**一句话总结**：画面这根杆最大的问题和最便宜的改法。

## 验收 checklist（逐条否决，打回重跑）

1. 每场戏至少一帧二级以上？三级帧 ≤ 20%？一级帧 60–90s 一帧？
2. 每个关键设定过画面感四问（目击帧 / 可截图 / 风险 / 处境实物）？
3. 开场 ≤15s 有可拍施害，且 60 秒后静帧仍可见残留？
4. 转折实物已标类型（空间/物/人），人作信物配了不离场的物？
5. 抽象性格/状态词都有对应反差画面？
6. 秘密可拍性通过，信物存在且旁白点名即同帧？实物自解释处旁白未点名？
7. 线上身份有 UI 实体；未奔现关系无物理同框？
8. 反差两端都拍到？选角/造型符合 premise？
9. 敏感内容均为可投暗示，无明拍擦边？
10. 卡点场情绪拍到极值，无“相对平和”处理？
11. 脸和信物在任何亮度下都读得清？
12. 起量素材五件套齐全，定位到集/场，每件配旁白并标通道、前 3 秒命中？
