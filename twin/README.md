# 分身 · 可玩 Demo

私密社交 + 用户分身 Agent 的第一个可玩版本：**你和自己的分身对话 → 分身替你在圈子里"在场" → 真正重要的时刻把你请出来**。
设计依据见 [`../docs/private-social-self-agent.md`](../docs/private-social-self-agent.md)。

## 运行

```bash
cd twin
npm install

# 不需要 API key，分身的措辞为预设文本，用于走通完整流程
npm run dev:mock

# 接真实 Claude（需要 ANTHROPIC_API_KEY）
export ANTHROPIC_API_KEY=sk-ant-...
npm run dev
```

打开 http://localhost:5174 。生产模式：`npm run build && npm start`（端口 8788）。

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `CHAT_MODEL` | `claude-opus-5-5` | 分身措辞、动态草稿、简报所用模型 |
| `CHAT_EFFORT` | `low` | 推理强度；分身口气不够像时调到 `medium` |
| `MOCK_AI` | 未设置 | 设为 `1` 时不调用 API |
| `PORT` | `8788` | 服务端端口 |

## Demo 流程（约 5 分钟）

1. **建立自我圣经**（3 步，已预填）：你怎么说话、分身永远不碰的事、每个朋友在哪个圈层。
2. **分身的早间简报**：圈子里昨晚发生了什么、谁找你了、它替你做了什么、哪件事该你亲自出面。
3. **处理卡片**：
   - 小雨（内圈）问你爸的身体 → 在范围内，但等级是 L0，分身把草稿留给你：就这么回 / 改一下 / 我自己回。
   - 阿杰（亲近）约周六打球 → 分身根据日历起草，不替你承诺。
   - Lena（一般）问你心情 → 范围外，分身只说"等他自己说"，什么都没透露。
   - 老周发了「我和她分开了」→ 分身**不代回**，提醒你亲自说一句。
4. **记一下**：输入"今天爬了佘山，腿废了"，点 📷 再点「记一下」→ 分身用你的口气起草 → 发 → 圈子里显示为**本人**。
5. **日志 / 授权**：把阿杰升到 L2 → 等待中的回复自动发出并进日志；升到 L1 以上，分身会给朋友的普通动态回表情（分手那条不会）。每条都能撤回，撤回时分身会告诉对方"刚才那条是分身说的"。
6. **朋友视角**（右上角）：切到任何一个朋友的手机，问分身问题。试试"能借我两千周转一下吗"（边界，不透露）、"周六几点有空"（Lena 是一般圈层，行程范围外）、以及「等真人回我」（分身立刻退出，你的手机上出现待办）。

## 结构

```
shared/types.ts       圈层 / 自主等级 / 话题 / 自我圣经 的类型与映射
server/policy.ts      规则层：话题分类、边界、危机、允许的最高动作、对模型输出的降级（guard）
server/prompt.ts      Prompt 分层：分身准则（可缓存）→ 自我圣经（可缓存）→ 对象关系 → 任务
server/mock.ts        无 API key 时的预设措辞（动作仍由 policy 决定）
server/index.ts       /api/twin/answer · draft · brief · chat
src/App.tsx           状态与所有动作：代答 / 草稿 / 范围外 / 交给真人 / 撤回 / 授权变更的重评估
src/components/       Onboarding · TwinChat · Circle · LogPanel · FriendPhone
```

## 设计上刻意做的几件事

- **模型只负责措辞，规则层负责边界。** 不管模型说什么，服务端的 `guard()` 都会把超出该朋友圈层和等级的动作降级，并在 UI 上打「安全层降级」标记。危机类消息根本不进模型。
- **分身的内容永远有标识**，朋友视角里是「对方的分身」，你的视角里是「分身」。只有你确认过的内容才进圈子信息流。
- **分身的指标在日志页顶部**：替你做的事、修正 / 撤回率、你亲自出面的次数、「等真人」中的数量。方案里说的红线（真人内容占比、等真人触发率）从这里起步。

## Demo 没做的

分身间串门、L3 发起、位置 / 相册 / 通讯录接入、语音、多人真实账号。这些在方案 §9.1 里都被排除在 MVP 之外。
